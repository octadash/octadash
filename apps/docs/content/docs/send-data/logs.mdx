Octadash takes logs over OpenTelemetry (OTLP over HTTP), the open standard
almost every language has. The key goes in the `x-octadash-key` header.

## Notes

- `service.name` says which part of the product a line came from: `api`,
  `worker`, `payments`.
- Lines with a trace id link to the error and the request they belong to.
- Traces (`/v1/traces`) and metrics (`/v1/metrics`) go to the same address and
  are kept too.
- How long to keep lines is set per product in **Logs** > **Set up**. Older
  lines are deleted every night.
