mostra o normal de cada evento, funis e quem volta. Em um site que já tem o
script do Tráfego, adicione uma linha onde algo acontece: sem chave nova.

## Regras

- Nomes de evento em `snake_case`. Propriedades são opcionais.
- Nunca envie nomes, e-mails ou documentos. Eles são descartados de qualquer jeito.
- `signed_up` conta como cadastro sem configurar nada.
- `distinct_id` é a pessoa. O Octadash guarda só um hash dele.
