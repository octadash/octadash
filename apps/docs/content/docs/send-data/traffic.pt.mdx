Sem cookies e, por padrão, sem banner de consentimento. O script tem menos de
2,5 KB, acompanha a navegação em apps de página única e ignora visitas de
`localhost`. O mesmo script também relata os erros não tratados da página
(Erros) e envia eventos `track` (Uso), então você o instala uma vez por origem.

## Vários sites em um produto

O site, os docs e o app de um produto são origens separadas, cada uma com o seu
script. Em Tráfego, **Adicionar origem** dá nome e código a uma nova. A página
soma todas, e o card **Origens** mostra cada uma: clique em uma origem para ver
só os números dela.

## Opções

- `data-visitor="persistent"`: o navegador guarda um id aleatório, então quem
  volta conta uma vez só. Desligado por padrão; ligar é decisão sua, inclusive
  o consentimento onde a lei pedir. Configure por origem no painel.
- `data-local`: conta visitas de `localhost`, para testes.

## O que é guardado

Caminho, site de onde a pessoa veio (referrer), UTMs, navegador, sistema, aparelho e país. O
endereço IP nunca é guardado: o id do visitante é um hash de um sal do dia, do
produto, do endereço e do navegador, e quando o sal expira ninguém consegue
ligar dois dias. Robôs são guardados e mostrados à parte.

O país vem de um cabeçalho que o seu proxy adiciona (Cloudflare, CloudFront,
Vercel). Sem ele, fica vazio.

Já usa PostHog? O SDK web dele envia `$pageview` com os mesmos nomes, então
também preenche Tráfego. Veja [Vindo do PostHog](/pt/send-data/migrate#posthog).
