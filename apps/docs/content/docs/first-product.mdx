---
title: Create your first product
description: From a name to the first data, one area at a time.
---

<Steps>
<Step>

### Create the product with its name

Pick **New product** in the product picker and type a name, for example
"Pagebird". No URL and no platform: a product usually has parts in different
languages, so the platform is chosen inside each area.

</Step>
<Step>

### Open the product page

The product page has one card per area. A card that is not set up says what
the area does and has **Set up** and **I won't use this**. Leaving a card alone
already means "not now".

</Step>
<Step>

### Set up one area

**Set up** opens the area: what it does, the product's
[sources](/concepts#source) and **Add source**. A source is one part of the
product that sends data, such as "Site, Next.js" or "API, .NET". Adding one
asks for a name and a platform and shows the code for that platform with the
source's key filled in. The same code is in [Send data](/send-data).

</Step>
<Step>

### Watch the card change

Once set up, the card shows sample data, blurred, with an **Example** label.
When the first data arrives it becomes the area's summary: the main number, a
small chart and a link to the full screen.

</Step>
</Steps>

## Where alerts go

Add a channel in **Settings** > **Channels** (email, Telegram or a webhook) and
press **Send test**. Emergencies, such as a site down for 3 checks in a row,
go to the channels and to the red strip on top of every screen.
