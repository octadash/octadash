---
title: Seus próprios bancos
description: A imagem pronta com o seu Postgres, ClickHouse e Valkey, ou a partir do código.
---

O Postgres pode ser Neon, Supabase, RDS ou qualquer Postgres 16+. ClickHouse
(26.8 ou mais novo, porta HTTP) e Valkey (ou Redis 7+) também podem ser de
fora, mas o caminho suportado são os que vêm nos arquivos compose.

```bash
docker run -d --name octadash-web -p 3000:3000 \
  -e DATABASE_URL=postgres://... \
  -e CLICKHOUSE_URL=http://user:pass@clickhouse.example.com:8123/octadash \
  -e VALKEY_URL=redis://:pass@valkey.example.com:6379 \
  -e OCTADASH_URL=https://octadash.example.com \
  -e OCTADASH_INGEST_URL=https://ingest.example.com \
  -e OCTADASH_SECRET=... \
  ghcr.io/octadash/octadash:edge web
```

Rode a mesma imagem com `ingest` (porta 4000) e `worker` como comando, com o
mesmo `VALKEY_URL`. O worker também precisa de `OCTADASH_URL` (links nos
alertas) e do mesmo `OCTADASH_SECRET` do painel (ele decifra os canais de alerta).

## A partir do código

Precisa de Node.js 22.12+ (24 recomendado), pnpm 10, Postgres 16+, ClickHouse
26.8+ e Valkey 8+ (`pnpm db:up` sobe os três com Docker).

```bash
pnpm install
pnpm build
DATABASE_URL=postgres://... CLICKHOUSE_URL=http://... pnpm db:migrate
```

Depois inicie `apps/web` (`pnpm --filter @octadash/web start`), `apps/ingest` e
`apps/worker` (`node dist/index.js` em cada um).
